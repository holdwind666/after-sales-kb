# 使用案例

## 案例 A：在线表格模板查询

顾客原文：`充電できない`（无法充电）
用户说明：这是 06 switch 手柄

处理步骤：
1. 打开缓存目录（用户提供的根目录下的 `_售后模板缓存`）。
2. 读 `products.tsv`，按别名“06手柄”定位到 `switch手柄（楚腾飞）` 行。
3. 读 `faq/switch手柄（楚腾飞）.json`，匹配“无法充电/充電”条目，取 `template` 字段作为日文回复。
4. 检查 `facts/switch手柄（楚腾飞）.json` 是否有充电指示灯补充信息（06 充电时闪烁、充满长亮）。
5. 输出：命中依据 + 可直接发送的日文回复 + 内部处理要点（换线→拍视频→发新）。

参考回复模板（来自 FAQ）：
```
お客様
お世話になっております。お問い合わせいただきありがとうございます。
SWコントローラーが充電できない問題について、お手数ですが以下をご確認いただけますでしょうか。
充電ケーブルが正しく接続されているか？
ほかのケーブルに変更してみていただけますでしょうか。
もし充電ケーブルを交換しても解決できない場合、充電できない動画をこちらにご送信いただけますでしょうか。
よろしくお願いいたします。
```

## 案例 B：本地说明书查询

顾客原文：`バリカンの使いかたは？`（理发器怎么用）
用户说明：这是 GTS-6030 理发器

处理步骤：
1. 读 `products.tsv`，定位 `GTS-6030理发器（楚腾飞）`。
2. 读 `faq/GTS-6030理发器（楚腾飞）.json`，匹配“使い方/使用/锁机/注油”条目。
3. 读 `pdf_ocr/` 中对应说明书文本，找“使いかた”“各部のなまえ”章节补充细节。
4. 需要配图时，从 `pdf_pages/楚腾飞/理发器/` 取对应页面图（如第8页使いかた、第5页各部名称）。
5. 输出：分步使用方法 + 可发送日文回复 + 页面图路径（可选）。

## 通用提示

- 优先使用 `faq` 模板原文，不要自行改写模板内容；只在模板缺失时基于说明书整理。
- 内部处理要点（如“确认视频后发新”）只给用户看，不发给顾客。
- 若产品名在 products.tsv 中找不到，先检查是否有别名（06/05/SW 等），再考虑增量更新。
