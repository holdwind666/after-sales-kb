# after-sales-kb — 日本站售后知识库 Skill

基于本地说明书/演示视频文件夹与 WPS 在线表格（日本站售后对应方案表）的 Codex 技能：按售后模板生成日文回复、查询产品参数与配件、支持增量更新与联网兜底。

## 从 GitHub 安装（新电脑）

### 方式一：用 Codex 安装（推荐）

1. 打开 Codex，发送：

```
请安装 skill：after-sales-kb
仓库：https://github.com/<你的用户名>/after-sales-kb
```

2. 安装完成后重启对话即可使用。

### 方式二：手动复制

1. 把本仓库的 `after-sales-kb` 文件夹下载到本地；
2. 复制到 `C:\Users\<你的用户名>\.codex\skills\`；
3. 重启 Codex。

## 首次初始化（新电脑必做）

安装后第一次使用，告诉 Codex 按以下顺序引导：

1. 提供「说明书与视频」本地文件夹地址（例如 `E:\说明书与视频（第9台）`）；
2. 提供 WPS 在线表格网址，并用 **Chrome 打开保持登录**（有权限限制时必须）；
3. 确认每周自动更新开关（默认关闭；连续3次未命中会提醒增量更新）；
4. 学习两个案例（在线表格模板查询 + 本地说明书查询）；
5. 首次全量缓存（约1.5~2.5小时，只需一次）；
6. 环境自检（缺失依赖逐步引导解决）。

## 日常使用

把顾客原文和产品型号一起发给 Codex，例如：

```
顾客说：充電できない
产品：06 switch手柄
```

回答顺序：快速索引（秒级）→ 全文检索 → 3次未命中提醒增量更新 → 联网兜底 → 明确告知无模板。

## 目录结构

```
after-sales-kb/
├── SKILL.md                  # 技能主文件（流程与规则）
├── agents/openai.yaml        # UI 元数据
├── scripts/                  # 环境自检、未命中计数、缓存构建脚本
├── references/               # 使用案例、故障排查、缓存构建文档
└── assets/bootstrap/         # 初始 settings.json / miss_counter.json
```

## 重要注意事项

- 知识库内容以**当前电脑上用户提供的内容为准**；
- 原始说明书/视频/图片和在线表格**只读**，写入只发生在 `_售后模板缓存` 目录；
- 新电脑首次使用必须重新做全量缓存（路径不同，不能直接拷贝旧缓存）；
- 每周自动更新默认关闭，需要时显式启用；
- 在线表格需要权限时，必须用 Chrome 打开并保持登录。
