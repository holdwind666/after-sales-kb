# 客服知识库管理技能（after-sales-kb）

日本站 Amazon 售后客服的 Codex 技能：基于本地说明书、WPS 在线表格（日本站售后对应方案表）和 ChatGPT 历史对话学习库，回答售后问题、按模板生成日文回复、查询产品参数与配件。回答得越多，知识库越准。

## 一分钟看懂它怎么用

装好技能后，把顾客原文和产品型号发给 Codex，例如：

```
顾客说：充電できない
产品：06 switch手柄
```

Codex 会：秒级检索知识库 → 按你的风格生成可直接发送的日文回复 → 自动把这次处理沉淀为学习案例。

## 安装（新电脑 2 分钟）

### 方式一：用 Codex 安装（推荐）

新电脑打开 Codex，发送：

```
请安装 skill：after-sales-kb
仓库：https://github.com/holdwind666/after-sales-kb
```

### 方式二：手动复制

1. 下载本仓库 ZIP（Code → Download ZIP）或 `git clone https://github.com/holdwind666/after-sales-kb.git`；
2. 把 `after-sales-kb` 文件夹复制到 `C:\Users\<你的用户名>\.codex\skills\`；
3. 重启 Codex。

## 首次初始化（新电脑必做，Codex 会一步步带你）

第一次使用时，告诉 Codex“初始化售后知识库”，它会按以下顺序引导（全程由 Codex 代替你执行命令，你只需要提供信息和偶尔点一下按钮）：

1. **提供本地文件夹地址**：说明书与视频所在目录（如 `E:\说明书与视频（第9台）`）；
2. **提供 WPS 在线表格网址**：用 Chrome 打开并保持登录（有权限限制时必须）；
3. **选择自动更新频率**：每周一次（推荐）/ 每天一次 / 暂不自动更新；
4. **首次全量构建缓存**：约 1.5~2.5 小时，只需做一次；
5. **环境自检**：Codex 检查并解决缺失项；
6. **说明知识库成长方式**（Codex 会主动告诉你）：
   - **日常自动学习**：每次售后问答自动沉淀，无需操作；
   - **可选历史导入**：ChatGPT 网页端历史对话可一次性补入（约 5–15 分钟），想补就说“导入 ChatGPT 对话”。

## 日常使用

### 回答售后问题（最常用）

```
顾客说：風量は調整できない、箱はボコボコ
产品：6228折叠吹风机
```

Codex 输出：命中来源 + 可直接发送的日文回复 + 内部处理要点（是否发新等）。

### 查询产品参数

```
产品：V10吸尘器
问题：线长多少
```

### 导入 ChatGPT 历史对话（可选，一次性）

```
导入 ChatGPT 对话
```

Codex 会给你两个方案选择：

| 方案 | 你需要做什么 | 预计耗时 | 说明 |
|---|---|---|---|
| A：自动抓取（备选） | 在独立窗口登录一次 ChatGPT | 1–3 小时 | 全自动但慢，受限流影响 |
| B：扩展导出（推荐） | 装导出扩展、点几下、给路径 | 5–15 分钟 | 快、稳定、支持按项目导出 |

### 学习进度与缺口

```
知识库目前学了多少东西
```

或让 Codex 运行 `build_gap_report.py` 查看知识缺口清单。

## 目录结构

```
after-sales-kb/
├── SKILL.md                  # 技能主文件（流程与规则，Codex 自动读取）
├── agents/openai.yaml        # Codex 界面显示元数据
├── scripts/                  # 检索、缓存构建、ChatGPT 学习、环境自检脚本
├── references/               # 使用案例、故障排查、缓存构建、ChatGPT 学习文档
└── assets/bootstrap/         # 初始配置模板
```

## 数据与隐私

- 知识库内容以**当前电脑上用户提供的内容为准**；
- 原始说明书/视频/图片和在线表格**只读**，写入只发生在 `_售后模板缓存` 目录；
- ChatGPT 学习数据存放在 WPS 云同步目录 `售后AI学习库\`（同一 WPS 账号的电脑自动共享）；
- 仅限内部使用。

## 常见问题

| 问题 | 解决 |
|---|---|
| 安装了但没生效 | 重启 Codex 或新开对话 |
| 未命中 3 次提醒增量更新 | 这是正常机制，说“执行增量更新”即可 |
| 需要图片/识图 | 先告诉 Codex 图片位置，确认需要下载/识图后再操作 |
| 新电脑缓存没同步 | 首次初始化必须重新全量构建（路径不同，不能直接拷贝旧缓存） |

## 更新技能

技能内容更新后需要重新安装一次（不会自动热更新）：删除 `C:\Users\<用户名>\.codex\skills\after-sales-kb`，再按安装步骤重装。
